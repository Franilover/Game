# Cabello

Añade aquí sprites PNG/WebP transparentes de peinados. Para superponerlos al cuerpo actual, usa exactamente el mismo lienzo, escala y origen que `assets/art/characters/Sprite-0004.png`. El color elegido por el jugador multiplica los píxeles del sprite; conserva sombras en grises y transparencia para que el tinte respete el sombreado.
